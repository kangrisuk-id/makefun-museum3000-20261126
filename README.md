## 🏛️ Exhibit № 3000 — Now on Display

> **Proof of Humanity (c. 2023). To open their own accounts, citizens proved they were not machines by finding every traffic light in a picture grid for one, unpaid.**

*One line. 161 characters. Chosen from 40 candidate labels in a scored knockout
tournament judged against the bounty's own five criteria, in the brief's order —
on-subject first, first-read laugh second, the year-3000 misreading third,
deadpan label voice fourth, freshness last. Local score: 24/25.*

A tiny, deterministic Python program (standard library only) writes that single
museum label to `entry.txt`. No clock, no randomness, no network — the same
label, byte for byte, every run.

| | Inside this entry |
|---|---|
| `main.py` | The program: holds the winning label and writes it to the output directory |
| `candidates.md` | All 40 candidate labels, per-criterion scores (/25), and the top-8 knockout |
| `README.md` | This file |

**How the winner was picked:** forty labels were drafted across fresh plinth
objects — a silica gel packet, a snooze button, a storage container whose lid
was never recovered — scored on all five of the judge's criteria, and cut down
through quarter-finals, semi-finals and a final. The CAPTCHA label won the
final on the brief's own tie-break order: its laugh lands on the first read,
and its absurdity is simply true.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
